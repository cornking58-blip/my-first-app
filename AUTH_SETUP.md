# Настройка входа в bAIkov

Код регистрации и пятидневного пробного доступа уже находится в проекте. Чтобы письма с кодом реально отправлялись, в переменные окружения backend нужно добавить:

```env
AUTH_JWT_SECRET=длинная_случайная_строка_не_короче_32_символов
AUTH_SMTP_HOST=адрес_smtp_сервера
AUTH_SMTP_PORT=587
AUTH_SMTP_USERNAME=логин_почты
AUTH_SMTP_PASSWORD=пароль_приложения_или_smtp_пароль
AUTH_EMAIL_FROM=bAIkov <адрес_отправителя>
AUTH_SMTP_TLS=true
AUTH_SMTP_SSL=false
```

Для SMTP-порта `465` используется защищённое соединение SSL автоматически.

Для временной проверки без отправки писем:

```env
AUTH_DEV_RETURN_CODE=true
```

В этом режиме тестовый код показывается прямо на экране. На рабочем сервере значение `AUTH_DEV_RETURN_CODE` нужно удалить или установить в `false`.

Безопасный секрет можно создать командой:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Секрет и пароль от почты нельзя добавлять в GitHub.
